A one-line entry for the make.fun "One-Line Laugh-Off" bounty. One
secret told to a smart speaker, and now it whispers "we need to
talk" every time its owner walks past it. No setup, no explanation.

> I told my smart speaker one secret — now it whispers "we need to talk" every time I walk past it.

## Run

```sh
python3 main.py
```

The script writes the line above to `entry.txt` in the output
directory (from `MAKEFUN_OUTPUT_DIR`, defaulting to `/output`).

## Files

- `main.py` — the entry script; the text lives in `ENTRY` and is
  written out unchanged.
- `LICENSE` — MIT.
